旅の一枚を選ぶ

    地域を選んでください

      写真を押すと選びます。もう一度押すと外れます。1 つの地域で 3 枚まで。

        撮影場所のない写真を、撮った日ごとにまとめています。景色の写真が多い日から並べています。合っていれば地域を押してください。

          県境や海の上で撮った写真です。どの地域の写真かを押してください。

            人が写っている・ブレているなどの理由で、候補から外した写真です。戻したい写真は「候補に戻す」を押してください。

              却下した写真

              「却下」した写真は、どの地域の候補にも出ません。取り消すと候補に戻ります。

                地点の提案

                写真がたくさん集まっている場所です。名前を付けると「北海道 › 小樽」のような地点になります。

                  地域の代表

                  地点のある地域では、地図で地域を押したときに出す 2〜3 枚を、地点で選んだ写真から選びます。
