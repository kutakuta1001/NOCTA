相手が、覚えている

前回の話題、次の旅行、好きなビール。常連は会った日を数え、三日・七日で新しい会話が開く。先週ぶりなら、そう言って迎える。

帰り道の手帳

会話が終わると、あなたの言葉と「こう言える」を並べた手帳が届く。残したい一言はフレーズ帳へ。翌日からは紙ナプキンのカードで復習。

ある夜の、一往復。

仕組み。

相手の言葉
Claude が常連の人格と場面を演じ、ミッションの達成を見て会話を締める。ふりかえりの分析も同じ。
相手の声
ElevenLabs と Gemini の音声合成。人物ごとに声を変え、文ごとに生成して、話し始めたらすぐ鳴る。無料枠を使い切ると次の声に切り替わる。
あなたの声
ブラウザの音声認識（Chrome）。聞き取りを確認してから送るので、言い直せる。
記憶と復習
会った日・覚えたこと・フレーズ帳は、作者の Mac の中の SQLite に。復習は FSRS で間隔を決める。
画面
PWA。人物はすべて手描きの SVG で、まばたきと口の動きだけを持つ。言葉と声は AI、絵は人の手。

サーバーは作者の Mac で動き、Tailscale Funnel で外から届くようにしている。入口は接続トークンで閉じているため、訪問者が開いても会話はできない。設計の記録は手元の仕様書にあり、コードは非公開。
