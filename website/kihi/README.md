# HiNa Kihi

「銀猫が見つけた、かたちの記憶。」HiNa Collection 第四部、家紋を眺める静的 WebApp。

## 開く
リポジトリの `website` をHTTPサーバーで配信して `/kihi/` を開く。
例：`python3 -m http.server 18781 --bind 127.0.0.1 --directory website`
ES Modules を使用するため file:// では開かない。ビルド・npm install は不要。
本番予定URL：`https://kutakuta1001.github.io/NOCTA/kihi/`。mainへのpushは別途公開操作。

## 使い方
- 「眺める」：三十の家紋、前後、次の出会い、今日の紋（日本時間）。
- 棚：家紋・家名・武将名・ひらがな読みで検索。「花と葉」「鳥と蝶」「道具と結び」「円と線」「留めた紋」で絞る。
- 「この紋を留める」：ブラウザの localStorage `hina:kihi:favorites:v1`。端末間同期なし。保存できない環境では画面内だけ保持し、その旨を表示する。
- 「しつらえる」：5配色、3配置、24文字までの一言。PNG 1200×1500で保存。言葉・配色・配置は永続化しない。
- `#oda` などのURL末尾で特定の紋を開く。履歴を増やさない。

## 構成
- `data.js`：紋・説明・創作の問い・歴史出典・配色・日付/ランダム選択。
- `art.js`：一括バンドルしたSVG図形。実行時の外部図案取得なし。
- `crests/*.svg`：外部原図19件の改変SVG（各作者・ライセンスは sources.html）。`art.js`と形を一致させること。
- `app.js`：鑑賞、絞り込み、ローカル保存、カード生成、PNG保存。
- `sources.html`：全30紋の歴史出典と図案ライセンス。データ追加時は `node website/kihi/generate-sources.mjs` で再生成する。
- `cover.svg`：Apps一覧用。独自作図の九曜を使用。
- `kihi.css`：NOCTA配色・レスポンシブ・reduced-motion。

## 図案と注意点
外部原図19件は Wikimedia Commons の公開図案を改変。CC BY-SA 3.0 が16件、Public domain が3件。保存画像にも各著者・原作品・ライセンスを残す。幾何の11紋は独自の鑑賞用作図（CC0）。家紋には時代・家系による異同があり、武将本人の所用品の完全復元とはしない。「想像の入口」は創作であり史実の解説とは分ける。
出典の文章は要約。猫画像は既存 `../img/cat/silver-sit.png` を参照。Google Fonts以外に外部リソース取得はなく、フォント通信が失敗しても主要機能は動く。

## 確認項目
PC・幅390/320pxで横はみ出しがないこと。全30紋表示、検索0件、植物11/鳥と蝶5/道具3/幾何11件、お気に入り保存と再読込・保存拒否、URL直接指定、今日の日本時間境界、次の出会いで同じ紋が続かないこと、配色/配置、日本語と記号の一言、PNG実寸と見た目、キーボードフォーカス、コレクションとの行き来を確認する。

追加図案の黒い縁取りや抜きを保つため、一部は輝度マスクを使用。ART内の `__MASK_ID__` は描画時に一意のIDへ置換し、棚・選択中・連続配置で参照が衝突しないようにする。原SVGとの比較で形の一致を確認する。
