感動したこと 使い方

The First Flower の一言日記を書き足すときの手順です。

書く感動の書きとめ帳（入力ページ）
作者専用。スマホのブラウザで開けます。claude.ai にログインした状態で開いてください。
見る感動したこと（公開ページ）
TFF の Profile 節の「感動したことを読む →」からもたどれます。

書いて載せるまで

  1. 入力ページで、日付・本文（3 文ほど）を入れて「残す」を押す。日付は思い出した日ではなく、感動した日にする。
  2. 長く書きたいときはブログに書き、その記事の URL を「ブログ記事の URL」に入れる。
  3. 写真を付けたいときは「写真を選ぶ」で 1 枚選ぶ。写真はサイトに公開されるので、人の顔が写っていないかを確かめる。
  4. 曲を添えたいときは、YouTube の共有ボタンでコピーした URL を「曲のリンク」に貼る。途中から流したいときは、YouTube の共有で「開始位置」に印を付けてからコピーする。写真と曲は両方付けられる。
  5. 載せたくなったら、Claude Code に 日記を反映して と伝える。
  6. Claude が載せる内容を一覧で見せるので、確かめて OK を出す。続けて コミットプッシュして と伝えると、本番に出る。

入力ページに残しただけでは、サイトには出ません。必ず 5 の確認を通ります。

直す・消す

  • 入力ページの一覧で「直す」を押すと、上の欄に中身が戻る。直して「直して残す」を押す。
  • 「消す」を押すと確認が出る。まだ載せていないものはその場で消える。載せたものは、次の反映でサイトからも外れる。
  • 載せたものを直したり消したりしたら、また 日記を反映して と伝える。

入力ページの印

未反映まだサイトに載っていない
直した・未反映載せたあとに直した。次の反映で、サイトも直る
反映済みいまサイトに載っている内容と同じ

花の咲き方

  • 1 件書くごとに花びらが開き、6 件で一輪が満開になる。7 件目からは次の花が咲き始める。
  • 年の中で、日付の古い順に 6 件ずつ一輪になる。思い出した順に書いても、載るときは日付順に並ぶ。
  • 年が変わると新しい花から始まる。2026 年の一輪目は桜で、二輪目からは コスモス → マーガレット → 椿 → ネモフィラ → ひまわり の順。
  • 前の年は、一輪目の花が一年ずつ順にずれる（2025 年はコスモス、2024 年はマーガレット）。
  • ある年の花を変えたいときは、Claude に「2027 年は椿にして」のように伝える。

困ったとき

  • 入力ページに「作者専用です」「保存先につながりませんでした」と出る: claude.ai にログインし直して開く。
  • 写真の欄が出ない: ページを開き直す。それでも出なければ、写真を外して本文だけ残し、写真はあとで足す。
  • 写真が「読み込めませんでした」と出る: スマホの写真アプリで JPEG として書き出してから選ぶ。
  • 曲のリンクで「YouTube の動画の URL を入れてください」と出る: YouTube アプリの共有から「コピー」した URL を貼り直す。プレイリストやチャンネルの URL は使えない。
  • Claude が手順を覚えていないとき: 「docs/tff-kandou.md を読んで日記を反映して」と伝える。
