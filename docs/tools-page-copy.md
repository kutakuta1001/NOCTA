# Tools 紹介ページの書き方（正本）

NOCTA の HP に置く Tools の紹介ページと、Tools 一覧のカード説明文の書き方。
コミット時に copy-audit-guard（hook）が、ここに書いた基準での監査を求める。
新しい指摘は、このファイルに足すだけで次の監査から効く。

## 紹介ページとは

アプリの簡単な紹介を挟み、そこから入口のボタンでアプリ本体へ進む形のページ。
アプリ本体の画面（strategy・kihi・iro・flora・gems・still の `index.html` など）は対象にしない。
新しい Tools でこの形を取るものは、紹介ページを作った時点で、下の設定の `intro_pages` に足す。

## 基準

中心の問いは「初めて来た人が、試す前にこれを知りたいか」。答えが「いいえ」なら削る。

- 紹介ページは、アプリの簡単な紹介。説明書ではない
- 構成は lampnook を手本にする。見出し、ひとことの説明、入口のボタン、短い項目の順
- 各項目は 1〜2 文が目安。項目の数は、迷ったら少ないほうにする
- 書かないもの
  - 作者用の情報（灯りの表示・接続トークン・作者用の使い方・作者の Mac）
  - 技術名・サービス名（Tailscale・sql.js・FSRS・three.js・IndexedDB・PWA など）
  - 使えば分かる細かい挙動（「聞き返すと少しゆっくり返ってくる」「通算 N 夜で数える」）
  - 作り手の事情（「AI に書かせない理由」など）
  - 更新履歴のような見出し（「この秋、増えたもの」）
- 仕組みは原則書かない。残すのは、訪問者が使うかどうかを決めるのに要ることだけ
  - 例: 記録はブラウザの中だけに残る。API キーを自分で用意する
- 締めの一文は飾りを付けず、言いたいことだけにする
- 手描きの SVG・見本・画像は残す。直すのは文言だけ
  - 紹介ページは SVG が 1 行に長く書かれている。本文をまとめて書き直すと SVG まで消えることがある（2026-10-16 に一度起きた）
- 直し方は、言い換えて短くするより、項目ごと消すのを先に考える
- カード説明文は、1 枚で「何のアプリか」が分かる最短の形にする

## 事例

### 2026-10-16 Barside

CEO の言葉:「説明ページになっていることが気に障った。ここはアプリの簡単な紹介で、細かく説明するページではない」「裏の仕組みや、私だけが知ればいいことが多分に含まれていた」

CEO が消したもの:
- 作者の Mac の灯りの表示、作者用の入口と使い方（入口はフッターの「作者用」リンクに移した）
- 技術の説明（Tailscale・sql.js・FSRS など）
- 項目「聞き返していい」「旅先のバーを、先に一軒」「夜を数える」「手帳が少し厚くなった」
- 仕組みの「相手の言葉」「相手の声」「画面」と、注記
- 締めの飾り「カウンターの最後の灯り。」

最後に残ったもの: 約束 3 つ / 会話の見本 / 判子と黒板 / 仕組み 2 行（あなたの声・記録）/ 締めの一文「うまく話せなくても、大丈夫。」

### 2026-10-16 lampnook

「仕組み。」の節（画面・光・音・記録・形の 5 行と注記）を丸ごと外した。

## 監査済みの印

hook は、ステージ内容の tree ハッシュに対応する監査済みの印がないと、コミットを止める。印は次の手順を経てだけ付ける。

1. hook が示した tree を `scripts/copy-lint.py --export` で書き出し、`copy-auditor` で監査する
2. 「消す / 短くする / 残す」の一覧と、直した版を CEO に見せる
3. CEO が OK を出したら、見せた tree を指定して `scripts/copy-lint.py --mark <tree>` を実行する

CEO の OK なしに印を付けて hook を回避しない。

## 設定（copy-lint と hook が読む）

`max_sentences` は機械チェックの上限。CEO 承認済みの Barside のリード文が 3 文なので 3 にしている。目安は上の基準のとおり 1〜2 文。
Claude / ElevenLabs は禁止語にしない。API キーを自分で用意するという、使うかどうかの判断に要る情報として残っているため。

```json copy-audit-config
{
  "intro_pages": ["website/lampnook/index.html", "website/barside/index.html"],
  "card_file": "website/apps-data.js",
  "banned_terms": ["Tailscale", "Funnel", "sql.js", "SQLite", "FSRS", "three.js", "IndexedDB", "PWA", "Gemini", "接続トークン", "作者専用", "作者の Mac", "作者用の入口", "使い方（作者用）", "灯りを確かめ"],
  "banned_heading_patterns": ["この(春|夏|秋|冬)", "増えたもの", "新しく", "アップデート", "更新履歴", "What's new"],
  "max_sentences": 3,
  "card_desc_max_chars": 60
}
```
