写真を足す（いちばん楽な方法）

  1. Claude Code のチャットに写真を貼り、どこに足すかを書いて伝える。
    静岡に網代を追加して、この写真を載せて
  2. Claude が写真を取り込み、地域や地点に割り当てて、画面での見え方を確かめてから一覧を見せる。
  3. よければ プッシュして と伝えると、本番に出る。

スマホの写真は、元の画質のまま渡すと撮影日が残ります。LINE で送り直した写真は撮影日が消えるので、いつ撮ったかを一言添えてください。

決まりごと

  • 1 つの地域・地点に載せるのは 2〜3 枚。
  • 人の顔がわかる写真は載せない。写っていたら Claude が知らせて、切り落とすか外すかを聞く。
  • 写真を載せると、撮影した年月だけが出る（日にちと撮影場所は出さない）。

地点

  • 地点は、県や国の中を分けた小さな場所。県を押すと「◯◯の代表」の横に並ぶ。
  • いまある地点: 北海道（道北・道南・道央）、静岡（網代）、滋賀（琵琶湖）、アメリカ（東部・西部）。
  • 新しい地点は、名前と県を伝えれば Claude が作る。

自分で選ぶとき

  1. 写真を ~/Pictures/nocta-journey/おすすめ/ の下に入れる（地点ごとにフォルダを分けるとわかりやすい）。
  2. Claude に おすすめの写真を取り込んで、選ぶ画面を開いて と伝える。
  3. 開いた画面の「地域ごとに選ぶ」で 2〜3 枚を選び、「公開データを書き出す」を押す。
  4. Claude に プッシュして と伝える。

Google Takeout から大量に取り込み直すときの手順は、Claude 向けの手順書 tools/journey/README.md にある。

困ったとき

  • push が途中で切れる: Claude が小分けにして送り直す。それでも止まるときは、README の「ブラウザで写真を上げる」を Claude に案内してもらう。
  • Claude が手順を覚えていないとき: 「docs/tff-journey-guide.html と tools/journey/README.md を読んで」と伝える。
