# DTM 制作ガイド（注意点・補完ツール）

CLAUDE.md から分離した参照情報。Studio One での制作・ミックス作業を始めるときだけ読む。
対象環境: Studio One Pro / Synthesizer V Studio PRO / UR22C / MPM-1000 / Mac。
ステム分離・オーディオ→MIDI のツール比較は `nocta-tools.md`、RipX DAW の具体手順は
`~/rip x/RipX-StudioOne-guide.md` を参照。
最終更新: 2026-08-16

---

## 1. 制作前の設定（事故防止）

- サンプルレートは 44.1kHz / 24bit でプロジェクト・素材を統一する（Suno の WAV は 44.1kHz）。
  途中変更はピッチ・テンポ事故のもと。
- 曲の最初にソングの BPM とキーを設定する。コードトラック・タイムストレッチ・
  外部 MIDI 読み込みの精度がすべてこれに依存する。
- UR22C のバッファサイズ: 録音時は小さく（64〜128 samples・レイテンシ優先）、
  ミックス時は大きく（512〜1024・CPU 余裕優先）。
- dspMixFx のループバックは通常 OFF。ON のまま録音するとフィードバックや二重録りになる。

## 2. ゲインステージングとヘッドルーム

- 各トラックのピークは -18〜-12dBFS 程度に収める。フェーダーを上げる前に入力ゲインで調整する。
- マスターのピークは -6dBFS 程度の余裕（ヘッドルーム）を残す。
- ミックス中はマスターにリミッターを挿して音量を稼がない。音圧はマスタリング段階の仕事。
- ラウドネスの目安: 配信向け -14 LUFS。ポップス・ロックの仕上げは -10〜-14 LUFS。
  計測は Youlean Loudness Meter（無料）。

## 3. モニタリングと耳の管理

- 小さめの音量で長く作業し、大音量チェックは短く。1 時間ごとに耳を休める。
  疲れた耳は高域とリバーブの判断を誤る。
- ヘッドホンだけで完結させない。スピーカー・スマホ・イヤホンでも確認する。
- リファレンス曲（目標とする市販曲）と音量を揃えて交互に聴く。

## 4. データ管理

- 「名前を付けて保存」でバージョンを残す（大きな変更の前に必ず）。
- 外部素材（Suno の WAV・分離ステム等）はソングフォルダにコピーしてから使う
  （Studio One のメディア迷子・リンク切れ防止）。
- 週 1 回は外付けまたはクラウドへソングフォルダごとバックアップする。

## 5. 権利まわり

- Suno 楽曲の商用利用は Pro プラン（月額 10USD）以上が必須。無料プラン生成物の商用利用は規約違反。
  有料プラン中に生成した曲の利用権は解約後も維持されるが、著作権の帰属までは保証されない。
- 2026-07-31 の GEMA 対 Suno ミュンヘン地裁判決（学習・出力両面の著作権侵害認定）以降、
  商用利用の法的基準は厳格化。米国では RIAA 訴訟も係属中。素材利用の前提は都度再確認する（`nocta-tools.md` 参照）。
- NOCTA のリリース曲に Suno 由来素材（オーディオ・MIDI とも）を使う場合は、
  フェーズ4の copyright-agent 確認を必ず通す。MIDI 化しても出所が Suno である事実は変わらない。
- 他人の市販曲を分離・MIDI 化しても元曲の著作権は消えない。公開・配布は不可。学習・耳コピ用途に留める。
- サンプル・ループ素材はロイヤリティフリーかを確認してから使う。

### ピッチ編集・オーディオ→MIDI

- Melodyne Essential: Studio One Pro に同梱（ARA 連携でイベントを直接開ける）。
  ボーカル・単音楽器のピッチ修正と MIDI 抽出はまずこれ。
- ステム分離・MIDI 化の選択肢一覧（LALAL.AI / RipX DAW / Suno Studio / UVR / Basic Pitch）は
  `nocta-tools.md` の該当セクションを参照。

## 7. 進め方のコツ

- 作曲・編曲・ミックスを同時にやらない。工程を分けると各判断が濁らない。
- AI 変換 MIDI（RipX / Suno Studio 由来）は骨格として使い、ベロシティとタイミングは手で直す。
  そのままだと機械的すぎるか、逆に誤検出でよれる。
- 1 曲を完璧にするより数を作る。判断力は完成数に比例して上がる。
