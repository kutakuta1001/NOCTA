## 合意事項（Acceptance criteria 4点）

### 1. コンセプト

- テーマ: 世界の美しい宝石・原石を「静かに眺める」図鑑アプリ
- 体験の核: 癒し（瞑想的な鑑賞体験）。産地・硬度などの知識ラベルは補助として併記可
- UX: スクロール型の1点鑑賞（NuWord stillの「めくる」体験を宝石の拡大鑑賞に転用）
- 「彩り」×「猫」の掛け合わせ: 銀猫演出をHP Statement帯と同種の実装パターンで1〜2箇所のみ配置（例: 宝石タップ時に肉球・絵の具インタラクション）。猫の常駐キャラクターUIは採用しない（宝石が主役）
- 見送り: お気に入り登録などのユーザー状態保存、「今日の一石」日替わり表示（動的処理が必要なため。反応を見て将来再検討）

### 2. 画像ソース方針

- 本体データ: オープンアクセス写真（Smithsonian Open Access / Wikimedia Commons）
- アクセント（ヒーロー画像など一部）: AI生成（GPT Image 2等・ChatGPT Plus手動生成）を併用するハイブリッド
- 出典表記: ライセンス条件に応じて個別対応（CC0は省略可、CC BY系は個別表記）。Wikimedia Commonsは画像ごとにライセンスが異なるため1点ずつ確認する
- 実画像はgitに追加しない（website/CLAUDE.mdルール準拠）。画像は外部URL参照を基本とする

### 3. 住所（リポジトリ）

- website/gems/ + GitHub Pages（still方式・静的構成）
- ビルドプロセス・DBなし。静的JSON/JSデータ + HTML/JS。git push即反映
- 相対パス必須（GitHub Pagesルール準拠）
- 収益化: 当面は無料公開。閲覧反応を見てからプレミアム化（Gumroadゲート再利用）を判断
- 将来ユーザー状態管理が必要になった時点でのみVercel + Supabase移行を検討

### 4. ブランド継承度

- 低〜中ハイブリッド
- NOCTA継承（変更不可）: 全体フレーム = nav / footer / タイポグラフィ（EB Garamond / Syne / Shippori Mincho系）/ 粒子ノイズ質感 / 余白哲学 / ベース warm-black #0A0906
- 自由領域: 宝石カードの背景色・アクセントは宝石ごとの色彩を主役にできる（個別可変）
- 参考: DESIGN.md §14はLP向け区分のため、Apps領域として「高」区分をベースに「低」区分の色彩自由度を部分導入する形
