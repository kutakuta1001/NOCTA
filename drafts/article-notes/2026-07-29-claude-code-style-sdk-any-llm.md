## 要約（3〜5行）
Hacker News 発の SDK の紹介。Claude Code スタイルのツール群（slash commands・プロジェクトコンテキスト・subagents）を OpenAI 含む任意の LLM エンドポイントに向けられる。コスト理由で ChatGPT API に固定されているが Claude Code の操作感が欲しい層向け。

## 主なポイント
- 「Claude Code 的ハーネス」の需要が SDK として切り出されるトレンド
- claude-code-router（別エントリ）と同じ「コントロールプレーンの価値」文脈
- サードパーティ SDK 経由の実行はデータ経路・品質の検証が必要
