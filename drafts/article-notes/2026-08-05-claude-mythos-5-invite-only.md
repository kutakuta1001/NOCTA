## 要約（3〜5行）
Claude Mythos 5（`claude-mythos-5`）がモデル一覧に登場した。Fable 5 とスペック・価格を共有するが、一般提供はされていない。Project Glasswing の承認顧客に限定提供され、招待制の Claude Mythos Preview（`claude-mythos-preview`）と組み合わせて提供される。用途は防御的サイバーセキュリティワークフロー。セルフサービスのサインアップはない。

## 主なポイント
- Mythos 5 は Fable 5 と同スペック・同価格（$10 入力 / $50 出力 per MTok）
- 一般提供なし。Project Glasswing の承認顧客のみ（AWS / Google Cloud のアカウントチーム経由）
- 用途は防御的サイバーセキュリティに限定して案内されている
- Fable 5 自体は 2026-06-09 から Claude API / Bedrock / Google Cloud / Microsoft Foundry で GA

## NOCTAへの関連メモ
NOCTA からは選択できないため R-09 のモデル棲み分けに影響はない。`/claude-docs-review` スキルは「新モデル追加 → /model-review 推奨」と規定しているが、招待制・限定提供のモデルは対象外とする判断が妥当（この判断は同日スキルの Gotchas に明文化した）。model-lineup.md の更新も不要。
