## 要約（3〜5行）
Anthropic の Claude が単なる AI チャットボットを超え、推論・コーディング・エージェント・ワークフロー・
メモリ・セキュリティ・エンタープライズ展開を含む完全なエコシステムへ進化しているという整理。
「01 — Core Models」から始まる分類で、用途別に異なるモデルが提供されている点を挙げている。
いいね116・RT23。

## 主なポイント
- 領域分類: Core Models / 推論 / コーディング / エージェント / ワークフロー / メモリ / セキュリティ / エンタープライズ
- 「用途別に異なるモデル」という認識は R-09 のモデル使い分けと同じ枠組み
- 概観の整理であり、個別機能の新情報はない

## NOCTAへの関連メモ
NOCTA はこのエコシステムのうち Core Models（R-09）・コーディング・エージェント（AGENTS 節12種）・
ワークフロー（COST POLICY）・メモリ（auto-memory 14件）・セキュリティ（deny + hook）を既に使っている。
未活用はエンタープライズ関連のみで、これはスタッフゼロ型には該当しない。
外部から見た全体像と NOCTA の実装範囲がほぼ一致していることの確認材料になる。
