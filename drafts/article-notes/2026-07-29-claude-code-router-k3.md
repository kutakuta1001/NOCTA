## 要約（3〜5行）
Moonshot が claude-code-router をスポンサーし、Claude Code のセットアップ資産（hooks・CLAUDE.md・ターミナルワークフロー）を保ったまま K3 モデルにワンクリックで差し替えられるようにした。「モデルは交換可能になり、コントロールプレーン（ハーネス側）にレバレッジが移っている」という視点。

## 主なポイント
- CLAUDE.md・hooks 等の運用資産はモデル非依存の価値を持つ
- モデル乗り換えコストが下がり、ハーネス設計の巧拙が差別化要因になる
- サードパーティルーター利用は API キー・データ経路のリスク評価が必要

## NOCTAへの関連メモ
NOCTA はモデル乗り換え予定なし。ただし「資産はハーネス側に蓄積する」という考え方は、CLAUDE.md・スキル・model-lineup.md を丁寧に育てる現行方針の裏付けになる。
