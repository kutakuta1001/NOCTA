## 要約（3〜5行）
GitHub の「claude-howto」プロジェクト（40K Star）の紹介。チュートリアル集ではなく構造化された学習パスで、Claude Code を10モジュール（01-slash-commands から順に memory・skills・subagents・MCP・hooks・plugins・checkpoints 等）に分解して段階的に学べる。

## 主なポイント
- 公式ドキュメントは機能を説明するが「組み合わせ方」を教えない、という課題への回答
- 10モジュールの順序立てた学習パス（基礎→応用）
- 40K Star と参照実績が多く、新規メンバー・新環境立ち上げ時の教材候補

## NOCTAへの関連メモ
NOCTA は各機能を導入済みのため学習用途は薄いが、「機能の組み合わせパターン」のリファレンスとして新スキル設計時に参照する価値あり。
