Anthropic が修了証付きの公式 AI コースを18本、無料で提供しているという一覧投稿。Claude 101（日常業務での Claude 活用）、Master Claude Cowork（デスクトップでのエージェント型ワークフロー構築）、Claude Code 系などが並ぶ。いいね98・リポスト41・ブックマーク104。

## 主なポイント

- Claude 101 / Master Claude Cowork / Claude Code 系などのトラック構成
- 2026-07-29 のレビュー時点では「13本」として記録されており、本数が13→18に増えている

## NOCTAへの関連メモ
運用ルールへの影響はなく記録のみ。ただし前回（2026-07-29）の記録が「13本」で今回「18本」という差分は、公式学習リソースが継続的に追加されていることを示す。NOCTA では CEO 自身が Claude Code の運用設計をしているため、Master Claude Cowork（エージェント型ワークフロー構築）と Claude Code 系のトラックは、今回の最優先課題である CLAUDE.md スリム化やワークフロー導入の判断材料になりうる。
