## 要約（3〜5行）
「Tool Calling」と「MCP」は互換概念と思われがちだが、関連はあっても解決する問題が違う、という解説スレッド。Tool Calling は AI がツールを呼ぶ能力そのもの、MCP はツール接続を標準化するプロトコル層。

## 主なポイント
- Tool Calling = モデルの能力 / MCP = 接続の標準規格、というレイヤーの違い
- MCP はツール定義をサーバー側に置き、複数クライアントで再利用できる
- 概念整理系コンテンツとして初学者への説明に使いやすい

## NOCTAへの関連メモ
既知の内容で運用への影響なし。xmcp・vidIQ 等の MCP 管理（ツール総数80以下ルール）の背景説明として、対外的な解説時に流用できる。
