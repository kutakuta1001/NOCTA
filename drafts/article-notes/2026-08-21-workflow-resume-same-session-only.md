## 要約

動的ワークフローのドキュメントによると、実行の再開は同じ Claude Code セッション内でのみ機能する。
ワークフローが実行中に Claude Code を終了した場合、次のセッションはワークフローを新規に開始する。
また、停止時にまだ実行中だったエージェントは保存されず、再開時に最初からやり直しになる。

## 主なポイント

- 完了したエージェントはキャッシュされた結果を返すが、それはセッションを維持している場合に限る
- 「多くの小さなエージェントにファンアウトするワークフローは、1つの長いエージェントより多くの進捗を保持する」と明記されている
- 一時停止は `/workflows` から `p` キー。再開も同じ

## NOCTAへの関連メモ

R-15 は「セッションが切れても続きから再開できる状態を保つ」と定めているが、
ワークフローの進捗はこの原則の外にある。長時間のワークフローを回している最中に
セッションが切れると作業がすべて失われるため、COST POLICY の
「承認ゲートを含む工程を1つのワークフローにまとめてはならない」という制約は
中断耐性の面でも正しい。
