## 要約（3〜5行）
Claude Code の Chrome 統合により、ライブWebアプリケーションをブラウザ上で直接デバッグできるようになった。公式ドキュメントの「Claude Code をどこでも使用する」表にも掲載。

## 主なポイント
- 実ブラウザでの表示確認・デバッグを Claude が直接行える
- スクリーンショット・DOM 検証を対話的に実施可能
- Playwright スクリプトによる検証と使い分けができる（Chrome統合=対話的・Playwright=回帰テスト）

## NOCTAへの関連メモ
HP（website/）・HiNa 図鑑群のブラウザ検証は現在 Playwright 主体。デザイン確認や単発の表示崩れ調査には Chrome 統合が軽くて速い可能性。次回 HP 作業で試す価値あり。
