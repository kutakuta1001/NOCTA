## 要約（3〜5行）
（タイ語）Claude Code Templates は、agent・slash command・skill・hook・MCP・settings を1か所に集めた「持って行ってそのまま使える」
カタログで、1行コマンドで導入できるという紹介。良い部品が複数リポジトリに散らばっている問題への解。いいね57。

## 主なポイント
- agent / command / skill / hook / MCP 設定 / settings.json を横断するテンプレ集
- 1行インストール（インストール方式は未確認。導入時はスクリプト内容を読む）
- NOCTA のように自作60本超を持つ環境では、比較対象として「公開テンプレの書き方」を見る用途

## NOCTAへの関連メモ
自作スキルの記法が古くなっていないかを確認するとき、公開テンプレ集は参照物になる。ただし1行インストールは
collection-common の「シェル破壊系」に該当しうるため、導入するなら内容を読んでから。`/doctor prompt-audit` の方が安全な監査手段。
