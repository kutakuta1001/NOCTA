## 要約（3〜5行）
Claude Code v2.1.219 で Opus 5 がデフォルトの Opus モデルになった。/fast の対象は Opus 5・Opus 4.8（4.7 は除外）で、Opus 5 の Fast モードは $10/$50/MTok。claude-api スキルも Opus 5 をデフォルトとし、4.8 からの移行パスを備える。

## 主なポイント
- /model で「Opus」を選ぶと Opus 5 が使われる（明示的に 4.8 を使うには claude-opus-4-8 指定）
- /fast は Opus 5 / 4.8 で利用可（Fast $10/$50）
- Dynamic workflows のサイズガイドラインがデフォルト medium（15エージェント未満推奨）に

## NOCTAへの関連メモ
CLAUDE.md の「Opus 4.8 切替通知ルール」は旧モデルを指名し続けるため、`/model claude-opus-5` への更新が必要（反映提案済み・CEO承認待ち）。
