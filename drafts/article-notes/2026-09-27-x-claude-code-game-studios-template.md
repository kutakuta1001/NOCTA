## 要約（3〜5行）
ソロの AI ゲーム開発には1つのチャット窓では足りないとして、Claude Code Game Studios というオープンソースのテンプレートを紹介。
アイデア出しからリリースまでを段階化した AI 支援ワークフローを提供する。いいね5。

## 主なポイント
- 「1人 + AI エージェント群」で制作を回すためのフェーズ構造をテンプレ化
- アイデア → 設計 → 実装 → リリースの段階ごとに役割（エージェント）を分ける
- オープンソースで公開。構造の参照用

## NOCTAへの関連メモ
NOCTA も「CEO + AI エージェントチーム」で企画から公開まで回すスタッフゼロ型。ゲーム領域のテンプレは、Tools 領域
（アプリ開発）のフェーズ設計を作るときの比較対象になる。roadmap.md の Code 領域ロードマップと照らして構造を借りられる。
