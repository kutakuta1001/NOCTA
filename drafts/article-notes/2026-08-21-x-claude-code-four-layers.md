## 要約

「ターミナルを開く→プロンプトを書く→あとは AI に丸投げ」では Claude Code の本領は引き出せない、
重要なのはプロンプトではなく「仕組み」であり、大きく4つの層で考えるべきだという主張。
いいね680・ブックマーク1026・インプレッション12.5万で、収集した中で最も反応が大きい。

## 主なポイント

- 「プロンプトより仕組み」という主張は公式ベストプラクティスの「環境を設定する」節と方向が一致する
- 4層の具体的な内容はスレッド未展開。CLAUDE.md / スキル / hooks / サブエージェントの4層と推測される
- 2026-08-05 のレビューで「Claude Code の5つのアーキテクチャ層」という別ツイートを処理済み。層の数え方は書き手によって異なる

## NOCTAへの関連メモ

NOCTA の構成は既に多層（CLAUDE.md 4階層・60本超のスキル・hooks・エージェント定義）で、
「仕組みで解く」という方向は実践済み。この種のツイートは新知見ではなく
現行方針の裏付けとして扱うのが妥当で、層の数え方の流行を追う必要はない。
