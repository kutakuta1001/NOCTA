## 要約（3〜5行）
Anthropic が修了証付きの公式 AI コースを18本、無料で提供しているという紹介。
Claude 101（日常業務での Claude 活用）、Master Claude Cowork（デスクトップでのエージェンティックワークフロー構築）、
Claude Code、Claude Code in Action（長時間の hands-off セッション）、
Introduction to Model Context Protocol、Building with the Claude API（8時間の重量級）などが挙げられている。
複数アカウントが同じ内容を投稿しており、いいね179・RT58が最大。

## 主なポイント
- 全18本・修了証付き・無料
- Claude Code 関連が複数（101 / in Action）、MCP 単独コースもある
- Building with the Claude API は8時間という規模
- 同一内容が複数アカウントから拡散されている（情報の一次性は低い）

## NOCTAへの関連メモ
「Claude Code in Action — 長時間の hands-off セッションを信頼できる形で回す」は
NOCTA が実際に直面している課題（無人実行時の検証・承認ゲートの設計）に近い。
Introduction to MCP は現在の xmcp 運用（読み取り専用2ツール）の設計妥当性を確認する材料になりうる。
ただし NOCTA は既に実運用に入っているため、コースの優先度は高くない。
