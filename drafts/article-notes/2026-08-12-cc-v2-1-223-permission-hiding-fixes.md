## 要約（3〜5行）
Claude Code v2.1.223 で、権限チェックからコマンドの一部を隠蔽できる不備が2件修正された。1件目は細工したコマンドが自身の一部を権限チェックから隠せたもの、2件目はタブや不可視 Unicode でパディングされたコマンドが承認ダイアログから一部を隠せたもの。いずれも「表示・判定されている文字列が実行される文字列と一致する」という前提を崩す種類の不備である。

## 主なポイント
- 細工したコマンドが Bash ツールの権限チェックから自身の一部を隠せた
- タブや不可視 Unicode によるパディングで、承認ダイアログの表示からコマンドの一部を隠せた
- 同バージョンではワークフロースクリプトが動的 `import()` でサンドボックス外のコードを実行できた問題、エージェント定義の `bypassPermissions` が組織の bypass 無効化ポリシーを無視していた問題も修正されている
- v2.1.221 の zsh `[[ ]]` 回避と同じ脆弱性クラス（権限判定に渡る文字列の操作）

## NOCTAへの関連メモ
NOCTA の `approved-guard` hook は「PreToolUse に渡るコマンド文字列全体が見える」ことを前提に正規表現で判定している。この前提が本体側の不備で崩れればガードは素通りする。つまり自作ガードの実効性は Claude Code 本体の健全性に依存しており、バージョン追従が単なる機能追加の話ではなくガードの前提条件の維持になる。CEO 環境は v2.1.228 で両修正を含む。
