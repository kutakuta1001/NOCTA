## 要約

「Claude Code をインストールしただけで止まっている人向け」に、追加する価値のあるスキル22件を
用途別に分類して紹介したスレッド。すべて GitHub リポジトリで、直近1ヶ月に公開され、動作確認済みという。
最初の分類が「Context & Token Discipline」で、Graft（2,794★）が挙げられている。

## 主なポイント

- 分類軸が「何をするか」で切られており、コンテキストとトークンの規律が最初に来る
- Graft は Claude Code / Cursor / Codex / Gemini に横断的に効くツールとして紹介されている
- ブックマーク66・いいね31。1ヶ月以内の新しいスキルに絞っている点が実用的

## NOCTAへの関連メモ

NOCTA は60本超の自作スキルを持ち、コンテキスト規律は R-05 と SKILL.md 500行制限で担保している。
外部スキルを増やすとツール総数80以下の維持（MCP セクション）と衝突しうるため、
導入するとしても「Context & Token Discipline」分類の1〜2本に絞る判断が妥当。
