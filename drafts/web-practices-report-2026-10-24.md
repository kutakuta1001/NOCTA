## 適用しない項目と理由

- `.claudeignore` で不要なファイルを除外する（発見8の元記事）: Claude Code の公式ドキュメントでは確認できない。ファイルを読ませたくない場合の公式の手段は `permissions.deny` の `Read(...)` ルール。Gemini の要約か元記事の誤りの可能性が高い
- 「AI エージェントの自律性を最大限に活用し複雑なタスクを任せる」: R-10（CEO が自分で行うことは提案もしない）と衝突するため、音楽・映像の判断には適用しない
- CI/CD で出力トークンに上限を設ける: NOCTA の GitHub Actions は静的サイトの公開だけで、Claude を CI で動かしていない
- 各領域に特化したスキルを作る・CLAUDE.md をプロジェクトごとに置く: 既にスキル80本超・website/CLAUDE.md があり、むしろ常時ロード削減が課題
