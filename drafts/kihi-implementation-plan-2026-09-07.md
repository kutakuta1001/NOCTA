# HiNa Kihi — 実装計画 / 2026-09-07

## コンセプト
銀猫が古い箱のふたに見つけた、小さな紋。武家ゆかりの家紋を、歴史を知る入口としても、形から想像を広げる入口としても眺める。名前はユーザー指定 Kihi。HiNa Collection の第四部「紋」。

## 検討と選択
1. 武将の年表中心の図鑑：歴史情報の負担が大きく「眺める」から離れる。
2. 家紋を自由変形する制作ツール：紋の同定が曖昧になる。
3. **紋を眺める小さな展示室＋色と余白をしつらえる一枚**：形を保ち、鑑賞と創作をつなぐ。これを採用。

## 画面
```
HiNa Collection ←                           Kihi / 紋
銀猫が拾った、かたちの記憶。
[眺める] [しつらえる]
 ┌──────────────────┬───────────────┐
 │                  │ 01 / 織田家   │
 │   大きな銀の紋   │ 織田木瓜      │
 │                  │ 形の問い      │
 │  前  次の出会い  │ 留める / 出典 │
 └──────────────────┴───────────────┘
十二の紋   検索 / 形の絞り込み / 留めた紋
```
モバイルは紋→説明の一列。暖かい黒 #0A0906、銀 #B8B4AE、生成り #E8E0D0。Shippori Mincho / EB Garamond とシステム書体。HiNa と揃えつつ、主役を大きな家紋に絞る。下線 wipe は戻るリンクに適用（designer/patterns/underline-wipe-hover.md）。派手な常時アニメーションは置かない。

## 実装範囲
- 独立した静的 /kihi/。追加依存・API・ログインなし。
- 12紋：織田、武田、真田、北条、島津、毛利、細川、加藤、黒田、前田、明智、徳川。
- 次の出会い、前後、今日の紋（日本時間）、検索、植物/幾何の絞り込み、お気に入り（このブラウザ保存）、URLの紋指定。
- しつらえる：5配色・3配置・短い一言。1200×1500 PNG保存。引用図案の著者/ライセンスを画像にも記載。
- 図案は地元保存SVG。複雑な4紋はMukai氏のCC BY-SA 3.0作品を背景除去・単色化。残り8紋は基本形の鑑賞用作図。史実の唯一の正解とは扱わない。
- 武将の名はその家を知る手がかり。後世の図案を本人の実用品と断定しない。歴史説明と創作の問いは分ける。出典・図案クレジットを全紋で表示。
- HiNa の第四部と apps-data に登録。誕生HiNaは既存3分野のまま。
