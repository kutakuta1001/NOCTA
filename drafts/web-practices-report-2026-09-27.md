## 適用しない項目と理由

- 発見 #15 Claude コネクタ（Notion / Google Drive）連携: NOCTA はローカルファイル + git で完結しており、MCP ツール数80以下の制約に対して追加の価値が薄い。
- 発見 #4 のうち「アクセス制限とログ管理」: スタッフゼロ型で CEO 1名のため組織的な統制は不要。情報基準の明文化（低優先）のみ採用。
- 発見 #3 のナレッジグラフ構築: 専用ツール導入は過剰。article-notes の `related:` リンク（低優先）で最小限に留める。
- 発見 #20 の RTK による CLI 出力圧縮: ツール追加のコストに対し、NOCTA の Bash 出力量は小さい。必要になった時点で再検討。
