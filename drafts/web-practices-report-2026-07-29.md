## 要注意: git・シェル操作に関わる提案（CEOが内容を確認してから判断）

- クエリ4に「コードコミット時に自動でリンター/フォーマッターを実行するフック（pre-commit 相当）」の提案あり。NOCTA の git 運用は「website/ 以下の特定ファイルのみ手動 add・自動 git 操作なし」なので、導入する場合は対象を website/ の JS/HTML 構文チェックに限定し、コミット自体をトリガーにしない形（PostToolUse フックで編集時に構文チェック等）を推奨。自動適用はしない。
- クエリ4に launchd/cron による定時実行・ブラウザ/デスクトップ直接操作の自動化言及あり。R-03（SNS自動投稿禁止）・R-04（外部ツールはプロンプト文書出力）と衝突しうるため、対象を読み取り専用タスク（Routines での収集系）に限定する現行方針を維持。
