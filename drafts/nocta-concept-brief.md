# NOCTA ページ コンセプト・ブリーフ（他AIへの入力用）

作成日: 2026-09-11
対象: NOCTA トップページ https://kutakuta1001.github.io/NOCTA/ （実装は `website/index.html`）

この文書は、NOCTA のページが何のために存在し、何を伝えようとしていて、
猫やデザインに何が込められているかを、外部のAIが単体で理解できるようにまとめたものである。
数値・トークンの正本は `website/DESIGN.md`、意図と経緯の正本は `website/DESIGN-NOTES.md`。
両者が食い違う場合はライブサイトを正とする。

## 1. NOCTA とは何か

**Music × Visual × Words × Code の4領域を横断するクリエイティブスタジオ。**
音楽専門レーベルではない。CEO 1人とローカル環境のAIエージェント群だけで、
企画から制作・公開までを完結させる「スタッフゼロ型」の体制で運営されている。

4本柱は概念ではなく、ページ全体に構造として一貫して現れる。

| 柱 | 中身 | 色 |
|---|---|---|
| Music | 楽曲制作（SynthV ボーカル・DTM） | 赤 `#CC5B4A` |
| Visual | AIアート・PV（NFT連動） | 黄 `#D9A441` |
| Words | ブログ・コピー | 青 `#5586BE` |
| Code | Webアプリ・ツール | 紫 `#9472B8` |

この4色は About セクションの図、足跡の色、ステートメント帯の遊びに至るまで固定セットとして使い回される。
足跡には緑 `#4FA597` が5色目として加わる。

重要な前提: 楽曲制作は停滞ではなく「CEOのペースで進む1ストリーム」であり、
他の3領域は楽曲の進捗に依存せず独立に出力を続ける。ページもそう設計されている
（Music は現在 Coming Soon 表記、他の3領域は実作品が並ぶ）。

## 2. ページの目的

このページは作品カタログではなく、**一つの問いを提示する場**である。

> AIが多くを担う時代に、人間に必要なのは「遊び」だ。

伝えたいことは3つ。

1. **問いの提示** — AIが仕事と消費の多くを引き受ける時代に、人間の側に何が残るのか。NOCTA はそれに「創作」で答える
2. **実践の証明** — 音楽・映像・言葉・コードを一人（＋AI）で横断してやっていることを、作品数と実物で示す
3. **仲間への呼びかけ** — 「その問いを面白がれる人を、いつでも歓迎します」。受注のための営業ページではなく、共感で接続するページ

したがって訪問者に求める行動は「購入」ではなく「見る・読む・触る」である。
CTA は1ビューポートに1つだけに抑えられ、声高な訴求はしない。

## 3. 中心にある思想 —「遊び」

ページ全体を貫く一文は、ステートメント帯にある。

> 遊ぶことで人生を**彩ろう**。

「彩ろう」だけがイタリックのシルバーになっている。この一語がページ全体の鍵で、
**色 ＝ 遊び**、**彩る ＝ 人生に遊びを持ち込む** という比喩が、以降のすべての視覚設計に展開される。

フッターのタグラインがこの思想の要約である。

> AIと人間が、遊ぶように創る。
> 音楽・映像・言葉・コードを越境して、
> 遊びが、人生を彩るまで。

## 4. 猫に込められた思い（最重要）

### 4-1. 二項対立の構造

ページは縦スクロールを物語として使い、**「AI＝幾何」と「遊び＝猫」の対立**を通底させている。

- **幾何（AI）の領域** = 冷たく、構造的で、無彩色。回転する多角形・リング・脈動するドット・シルバーの球体
- **猫（遊び）の領域** = 温かく、手描きの水彩で、色を持ち込む

**ステートメント帯より前（Hero / About / Tools）には猫を出さない。** ここはAIの静かな区画である。
猫が現れるのはステートメント「遊ぶことで人生を彩ろう」以降だけ。
つまり**猫はこの一文の実体化であり、宣言のあとに世界が色づく**という順序そのものが主張になっている。

### 4-2. 物語のアーク（ページ上から下へ）

| 位置 | 出来事 | 素材 |
|---|---|---|
| About | 銀球体を囲む4本柱の点と線が赤・黄・青・紫に色づく | SVG |
| — | これは**伏線**。まだAIの領域だが、後で猫が出会って「遊び」になる色をあらかじめ置いている | |
| Statement | 銀猫が赤い絵の具皿に前足をつける。**物語の起点** | `silver-paint.png` |
| Portfolio | 見出し周りの空白に、色付きの水彩足跡が1つずつゆっくり現れる（猫が歩いて残した跡） | SVG + feTurbulence |
| Visual | 銀猫が座り、後ろ姿でギャラリーを眺める | `silver-sit.png` |
| Blog | 絵の具のついた足で歩く銀猫が見出しへ向かう | `silver-walk.png` |
| フッター直前 | 色付き足跡の水平な区切り線。旅の continuity | `paw-divider.png` |
| Footer | 猫が丸くなって眠る。**旅の終わり** | `silver-sleep.png` |

訪問者はスクロールしながら、無彩色の思考の領域から、色のついた遊びの領域へ移動し、
最後に猫が眠るところで旅を終える。読み終わりに「静けさ」が来る構成になっている。

### 4-3. なぜ銀猫なのか

イラストは黒猫と銀猫の両方が用意されている。
NOCTA の背景は warm-black `#0A0906` なので、**黒猫では消えてしまう**。
銀猫を選んだのは可読性の判断であり、黒猫はライト系の文脈用に取っておかれている。

### 4-4. 訪問者が「彩る」瞬間

ステートメント帯は、ページ唯一の**インタラクティブな遊びの場**でもある。
ポインタを動かす（タッチではタップする）と、その軌跡に水彩の肉球が残る。
色は4本柱の固定パレット。上限60個、`prefers-reduced-motion` では無効。

これは装飾ではない。**「遊ぶことで人生を彩ろう」という宣言を、訪問者自身の手で実演させている。**
語るのではなく、やらせる。だからこの仕掛けは他のセクションには絶対に足さない
（希少性がこの瞬間を特別にしている）。

### 4-5. 猫の運用ルール

- 猫は**間引く**。ページ全体で約5ビートのみ。全セクションには入れない
- **Tools セクションは意図的に猫なし・装飾なしでクリーンに保つ**。幾何アクセントを入れる案も検討されたが「入れない」で確定した。ここは"AIツール"の静かな区画であり、何もないことが心地よさになる
- Hero / About / Tools は幾何（AI）のまま
- 肉球と4本柱の色（赤・黄・青・紫）は固定セット。About と足跡の色の対応を崩さない

## 5. デザインに込められた思い

### 5-1. トーン

**dark editorial serif-led** — 落ち着いた、余白主体の、印刷物的なトーン。
声高ではなく、必要な箇所だけ静かに強い。

### 5-2. パレット（2026-06-15 確定）

| 役割 | 値 |
|---|---|
| アクセント（唯一） | シルバー `#B8B4AE` |
| テキスト | オフホワイト `#E8E0D0` |
| 背景 | warm-black `#0A0906` / surface `#0F0D0A` |
| サブテキスト | `#9A8A7A` |

**思想: アクセントは1色だけ。** ブランドの電圧は、色数ではなく「シルバーをどこに使わないか」で作る。
シルバーは CTA・section-tag・hover glow に限定される。色の壁は作らない。

経緯として、2026-06-04 に gold `#C4942A` からシルバー×オフホワイトへ変更した。
旧パレット（ネオングリーン `#39FF6A` / ラベンダー `#C8A2FF` / gold）は全廃されている。

### 5-3. タイポグラフィ

ロードするフォントは4種のみ。EB Garamond（セリフ大見出し）/ Syne（見出し・ラベル）/
Bebas Neue（数字・大文字）/ Noto Sans JP（日本語本文）。

**思想: 大きさで強調する。太さで強調しない。**
セリフ大見出しは font-weight 600 が上限で、強調はサイズとシルバーのコントラストだけで作る。

見出しには2つの方言があり、同一セクション内で混ぜない。

- Pattern A（Bebas / EB Garamond の大文字）= ポートフォリオ系。作品を「見せる」場
- Pattern B（section-tag + Noto Sans JP の見出し）= About / Contact。言葉を「読ませる」場

### 5-4. レイアウトの原則

1. **96px 以上のセクションリズム**（`py-32`）— 全帯で一定の呼吸
2. **サーフェスのリズム** — 同じ面を連続させない。`works` と `visual` は `bg-black/30` の沈み面、`about` / `apps` / `blog` は平面にして交互の抑揚を作る
3. **ステートメント帯（voltage moment）** — about と works の間に浮き面の全幅帯。大型セリフの一文＋一語だけイタリック・シルバー。色を足さずスケールと面の浮きで「山」を作る。**1ページに1つだけ**
4. **featured-first グリッド** — Works 先頭カードを横長にして、均質な3列グリッドの「スペックシート感」を崩す
5. **glass-and-noise first の立体感** — 影は最小。深さは半透明グラス＋常時のグレインノイズ＋ホバー時のみのシルバー glow で作る。glow は常時点灯しない
6. **アクセントの希少性** — プライマリCTAは1ビューポートに1つ
7. **About のシグネチャビジュアル** — 4本柱（Music / Visual / Words / Code）が中央の動くシルバー球体に収束する図。中央にテキストは置かない

### 5-5. アクセシビリティ

`prefers-reduced-motion: reduce` で、幾何ループ・猫のフェード登場・足跡・呼吸アニメーション・
ステートメント帯の遊びのすべてが停止する。猫の `<img>` は `aria-hidden` かつ `pointer-events: none` で、
読み上げと操作を妨げない。足跡は base opacity 0.55 を持ち、JS や監視が発火しなくても見える保険がかかっている。

## 8. やってはいけないこと

デザイン面:
1. 第2のアクセント色を足す（シルバー1色の原則を壊す）
2. 白背景・ライトモードを作る
3. gold `#C4942A` / ネオングリーン / ラベンダーを再導入する
4. ロードしていないフォント（Inter・Space Grotesk）を使う
5. セリフ大見出しを font-weight 600 より太くする
6. 同じサーフェスモードの帯を連続させる
7. ステートメント帯を2つ以上作る
8. glow を常時点灯させる
9. プライマリCTAを1ビューポートに2つ以上置く

猫・物語の面:
10. Hero / About / Tools に猫を出す（ここは幾何＝AIの領域）
11. Tools セクションに装飾を足す（クリーンに保つことが決定事項）
12. 猫を全セクションに入れる（約5ビートに間引く）
13. 4本柱の色（赤 `#CC5B4A` / 黄 `#D9A441` / 青 `#5586BE` / 紫 `#9472B8`）を変える、About と足跡の色対応を崩す
14. ステートメント帯以外に同種のインタラクションを足す（希少性が効果の源）
15. 黒猫をダーク背景で使う（消える）

コンテンツ面:
16. Music を「停滞」として扱う・他領域を楽曲の進捗に従属させる
17. 営業ページ的な訴求トーンにする（受注獲得ではなく共感で接続するページ）
18. ドキュメント・仕様書・UI文言に絵文字を使う（SNS投稿文とプレスリリースのカジュアル版のみ可）

技術面:
19. 絶対パスを使う（GitHub Pages でずれる。すべて相対パス）
20. 外部リクエストを増やす前に必要性を確認しない
21. `prefers-reduced-motion` の停止経路を持たない演出を足す

## 9. 周辺のコレクション（Tools からの導線）

トップページは3つのコレクションへの入口を持つ。いずれも「銀猫の物語がページの外へ出ていった先」という位置づけ。

**HiNa コレクション**（`website/hina/`）
トップページの銀猫ストーリー（絵の具→足跡→ギャラリー→歩く→眠る）から飛び出し、
**銀猫が単独で3つの静かな世界を巡る散歩**をWebアプリとして切り出したもの。

| アプリ | 世界 | 遊びのレイヤー |
|---|---|---|
| Gyu（`gems/`） | 宝石36種 | 石を光にかざす（3D・パストレーシング現像） |
| Ichi（`flora/`） | 季節の花24種 | 咲かせる（なぞると花が芽吹き、放置すると庭が仕上がる） |
| Hare（`iro/`） | 伝統色48色 | 筆あそび（その色のインクで書く） |

HiNa 体験原則の4カ条:
1. ひとつずつ、静かに眺める（1画面1点の鑑賞スクロール）
2. 今日のひとつが毎日変わる（日付シードで決定的に）
3. 気に入ったものに肉球の印をつける（お気に入り）
4. 眺めるだけで終わらず、遊んで跡を残す（遊びのレイヤー）

**NuWord コレクション**（https://nuword-nu.vercel.app ）
Zettelkasten 型の思考メモ（Seeds）と、言葉を眺める（Verse）。

**YORI コレクション**（https://nuword-nu.vercel.app/before ）
「書く前の、寄り道。」— 考えをまとめる前に心がよそ見する時間をつくる四つの小さな遊び
（けはい・みちくさ・かさね・あいだ）。

## 10. この文書を他のAIに渡すときの使い方

- **コピーを書かせる場合**: 第2〜3章（目的と思想）と第7章（確定コピー）を渡し、「声高にしない」「受注営業のトーンにしない」を明示する
- **デザインを触らせる場合**: 第5章（デザイン）と第8章（禁止事項）を必ず渡す。トークンの正本は `website/DESIGN.md`
- **猫や演出を扱わせる場合**: 第4章を全文渡す。二項対立の境界（ステートメント帯より前には猫を出さない）と希少性の原則が壊れやすい
- **判断に迷う場合**: ライブサイト（https://kutakuta1001.github.io/NOCTA/ ）を正とする。ドキュメントが古い可能性がある
