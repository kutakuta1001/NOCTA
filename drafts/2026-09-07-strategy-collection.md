# Kai — 実装・引き継ぎ

ユーザー承認「このまま進めてOKです」に基づく軍師コレクション。正式名称は Kai（2026-09-07 確定）。NOCTA の独立した静的ページとして実装し、HiNa の第五部と Apps に入口を追加する。本番への commit / push は実施しない。

## 体験と設計

コンセプトは「銀猫が古い書斎で見つけた、考えるための地図」。大きな図を見ながらゆっくり判断をたどり、自分の問いを残す。

検討した構成は、人物別の図鑑、名言中心のカード棚、地図と時間軸を中心とする書斎の三つ。図解・知見・仕事の三つを往復する今回の目的から書斎を採用。人物の英雄譚に偏らず、分析担当・司令部・現場の役割を分ける。

黒 #0A0906、銀 #B8B4AE、本文 #E8E0D0。セリフの見出し、広い余白、独自 SVG の地図が中心。青は水域、茶は対する側の機能色。色に加えて丸・菱形・破線・実線で区別する。画像、外部フォント、地図 API、CDN、依存ライブラリなし。既存 Kihi と同様に独立 CSS を使い、他コレクションに波及させない。

frontend-design スキルを適用。参照パターンは designer/patterns/underline-wipe-hover.md。テキストリンクのみに適用し、focus-visible と reduced-motion を用意。

## 実装済み

- `/strategy/` コンセプト、今日の一題（日本時間）、十二題の棚、時代・テーマ・言葉／人物検索、栞の絞り込み。
- `/strategy/study.html?case=garden&mode=map&step=0` 同じ題で「布陣を読む」「思考を拾う」「仕事に映す」を切り替える。
- 12題 × 4段階（状況・判断・展開・結果）。自動再生なし。図の拡大はネイティブ dialog、Escape とフォーカス復帰対応。
- 栞、題ごとのメモ（最大3000文字）、メモ一括 TXT 保存、出典付き1200×1500 PNG 保存。
- `/strategy/sources.html` 出典索引、資料の性格、引用の原文・本作訳・文脈。
- URL に case / mode / step を保持。無効値は妥当な初期値へ。戻る操作対応。

## 出典と表現の方針

content.js の sources が正本。2026-09-07 に公開資料の本文／検索結果を確認。NHHC と英国国立公文書館の一部本文取得はツールで失敗したため、公的サイトの検索結果、関連博物館の資料と突き合わせ、記述を目標推定・二重スパイの寄与などの高水準に限定した。学術的な全面校閲や戦史の網羅ではない。

- 孫子：Giles 1910 英訳本文、章・節を指定。英語を中国語原文とは表示しない。著者については伝承と記す。
- 高松城：岡山市の城跡・堤防解説。発案者、工期、正確な浸水域、和議の経緯は根拠なしに追加しない。
- ミッドウェー：NHHC と National Museum of the Pacific War。情報だけで勝ったという断定をしない。
- フォーティテュード：The National Archives の展示解説。個別工作の決定的効果を断定しない。
- マーケット・ガーデン、ソンム、カンブレー：National Army Museum。前線全体を代表する図とはしない。
- ダンケルク：English Heritage。小舟だけの功績にしない。救出と勝利を区別。
- 人工港：Historic England。掲載文に「surviving Mulberry A」という前後と矛盾する表記があるため、それを転載しない。嵐によるアメリカ側の被害と人工港の機能に絞る。
- Eisenhower：1957年演説で「以前に軍で聞いた」と紹介した文言。本人の創作・大戦中の発言とはしない。
- Drucker Institute：機関の effectiveness 定義。ドラッカー本人の発言として偽装しない。
- Churchill：英国議会の1940年6月4日議事録。
- Adam Smith：大学掲載の『国富論』第1編第3章の章題。会話中の発言とはしない。

引用と「拾った思考」「問い」「仕事への応用」（本作の編集）は明確に分離。すべての図は本作作図で、既存図版をトレース／転載していない。図は縮尺・実数・正確な航跡や位置を示さない。古典は実戦の再現ではなく概念図。当時の内心や確信度の復元は行わない。

## 保存の挙動

`localStorage` の `nocta:strategy:v1` に `{favorites: string[], notes: Record<string,string>}`。不明なIDや不正型は読み込まない。メモは入力ごとに保存するため、段階や題の切り替えで未保存タイマーが残らない。容量／権限制限時は画面内に保持し警告、TXT へ書き出せる。サーバー・ログイン・端末間同期なし。同じオリジンの別タブ同時編集は統合しない。既存の別アプリのデータには触れない。

## 2026-09-07 追加改修：18題と、考えをたどる5段階

ユーザーの「種類を増やす／布陣から思考・仕事へのつながりを丁寧に」という依頼を実装。

構成案は、同じページへの長い解説追記（全体を見渡せるが一度の読書量が増える）、クイズ形式（能動的だが正解探しになりやすい）、小さな段階で読む形式（操作は増えるが一段ずつ確かめられる）を比較。今回の「自分でつながりを補うまで時間がかかる」という課題に合わせ、最後を採用。

- 題を12→18へ追加。赤壁（chibi）、官渡（guandu）、長篠・設楽原（nagashino）、小田原（odawara）、第一次マルヌ（marne）、ダウディング・システム（dowding）。布陣は18×4＝72段階。
- 思考を拾うは全題で、①場面を確かめる ②判断のつながりを見る ③考え方に言い換える ④自分への問いにする ⑤関連する言葉を読む、の5段階（計90段階）。任意の段階へ移動でき、回答を強制しない。
- 図のどこを見るか、置かれた条件と選択、そこから考え方に移る理由を各題別に執筆。名言は最後に置き、なぜその引用を添えたかも説明する。
- 仕事に映すは「歴史の要素 → 読み取る関係 → 仕事での例」の対応表、具体的な進め方の変化、小さな行動の順。関連名言は補足に畳む。
- 図は左右のモードでも残し、元の布陣の特定段階への戻るボタン・拡大を用意。モバイルでは図と見る場所の小さな組み合わせにする。
- 布陣の結果から5段階への入口を追加。URLに think=0..4 を追加し、タブ切替・戻る・再読み込みで段階を保つ。別の題へ移ると0に戻す。以前のURLも動作。
- 既存のメモ保存キーと形式は変更していない。新しい自動保存データやマイグレーションなし。

追加ファイルは bridges.js（18題の橋渡し文・図の段階・対応語・具体例）と reflection.js（5段階と仕事への表示）。HTML/SVGに差し込む固定データもエスケープする。手書きメモは従来どおりtextareaのvalueで扱う。次の題のリンクは今の題から順に進む。
